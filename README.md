# 🃏 JS_BlackJack - El Clásico Juego de Cartas

¡Que empiecen las apuestas! Este proyecto es una recreación interactiva y digital del clásico juego de cartas BlackJack. El objetivo principal de este desarrollo fue construir una lógica de juego sólida utilizando capacidades nativas del lenguaje de programación para gestionar eventos, decisiones de los jugadores y reglas automatizadas de la banca.

Es un excelente ejemplo de cómo transformar reglas de un juego físico en funciones lógicas que controlan el estado de una partida en tiempo real, ofreciendo entretenimiento inmediato de forma directa en el navegador.

### ✨ Características Clave

* **Lógica de Juego Automatizada:** Control preciso del valor de las cartas, el conteo de puntos del jugador y las decisiones automatizadas que toma la banca según las reglas oficiales.
* **Manipulación Dinámica del Entorno:** El juego actualiza visualmente las cartas en la pantalla a medida que se piden o se plantan, sin necesidad de recargar la página.
* **Gestión de Estados:** Capacidad interna para determinar instantáneamente quién gana, quién pierde o si hay un empate basándose en la puntuación obtenida.
* **Uso Eficiente de Funciones:** Estructura de código limpia enfocada en probar diferentes métodos y algoritmos para optimizar el rendimiento y la velocidad del juego.
